# Right Wing Politics Website

This is a professional Next.js website for Right Wing Politics featuring:

## Pages
- **Home** - Welcome and featured content
- **Videos** - Video gallery and YouTube integration
- **About** - Mission, values, and channel information
- **Contact** - Contact form for inquiries
- **Donate** - Support the channel via Buy Me a Coffee
- **Privacy Policy** - Privacy terms
- **Terms of Service** - Usage terms

## Features
✓ Responsive design for all devices
✓ Dark mode support
✓ Fast performance with Next.js
✓ SEO optimized
✓ Social media integration
✓ Contact form
✓ Donation support links

## Setup

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`

## Environment Variables

Create `.env.local` with:
```
NEXT_PUBLIC_YOUTUBE_CHANNEL_ID=your_channel_id
NEXT_PUBLIC_YOUTUBE_URL=https://www.youtube.com/@YourChannel
NEXT_PUBLIC_BUYMEACOFFEE_URL=https://www.buymeacoffee.com/yourprofile
```

## Build

```bash
npm run build
npm run start
```
